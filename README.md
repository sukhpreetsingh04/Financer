# Financer (Personal Finance Tracker)
Financer is a budgeting application where users can log expenses. User can categorize spending and view monthly summaries.
A simple Android weather application built with kotlin and Jetpack Compose.
This project is being developed as a practical Android project to understand modern Android development concepts including Jetpack Compose, ROOM and MVVM.

## 🛠️ Tech Stack
- Kotlin
- JetPack Compose
- ROOM
- MVVM
